Who's the Spy with children: seven small changes that keep it fun

Ahmed Moaz · 13 November 2026

Who's the Spy is a game of bluff, and children can enjoy it if the grown-ups loosen a few things. These are the changes I would make.

1. Play in the same room

In Same room mode each person uses their own phone and the clue is spoken aloud. Younger children find speaking easier than typing.

2. Or share one phone

One phone skips the lobby. You type the names, the game deals the words and the phone goes round the table. Up to twelve people can play.

3. Use friendly packs

The host picks the packs. For children, pick toys and games, animals, fruit and vegetables or food. Words do not repeat at one table, so a long session keeps surprising.

4. Relax the clock

Online, a turn is 25 seconds. The host can pick a relaxed clock, which adds more time. In the same room, there is no clock to worry about.

5. Keep the spy count at one

More spies means more to hunt for. For children, one spy is plenty.

6. Let the spy have a helper

A parent can sit beside a young spy and whisper ideas for a clue. The game is about talk, and a team of two is still a game.

7. Make losing gentle

A spy who is caught still gets a go at the word. A civilian who votes wrong has still scored by taking part. Cheer for a clever clue, not only for the winner.

What to avoid

Do not use a pack that contains words children will not know. The aim is a laugh, not a quiz.

How long it takes

In the table log, the middle Who's the Spy game took 7.1 minutes, so one round fits into a restless child's attention.

Where to play

You can set up a children's table on Boardit's Who's the Spy, with three to eight online or up to twelve on one phone.

Gentle packs by size

Friendly packs are small ones. Animals has 24 pairs and Fantasy 16 pairs, so a children's table sees familiar creatures often, which is a feature: the more familiar the word, the easier the clue.

The changes in a line

Same room or one phone, simple packs, one spy, no rush.
